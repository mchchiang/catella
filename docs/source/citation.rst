Citation and License
=====================

Citing catella
---------------

If you use catella in your research, please cite it.

.. code-block:: bibtex

   @software{catella,
     author  = {Chiang, Michael},
     title   = {catella},
     url     = {https://github.com/mchchiang/catella},
     version = {0.1.0}
   }

Machine-readable citation metadata is also available in
`CITATION.cff <https://github.com/mchchiang/catella/blob/main/CITATION.cff>`_
at the repository root.
