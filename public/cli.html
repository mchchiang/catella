CLI Reference

catella

Nucleosome Positioning Monte Carlo Simulation Suite

Usage

catella [OPTIONS] COMMAND [ARGS]...

Options

--install-completion

Install completion for the current shell.

--show-completion

Show completion for the current shell, to copy it or customize the installation.

analyze

Compute post-simulation occupancy and nucleosome count statistics.

Usage

catella analyze [OPTIONS] DATASET_FILE

Options

--time <time>

Simulation time point

--occup-name <occup_name>

Key to store occupancy

Default:

'occup'

--mean-nnuc-name <mean_nnuc_name>

Key to store mean nucleosome count

Default:

'mean_nnuc'

--out-file <out_file>

Output file (default: overwrite dataset_file)

--overwrite, --no-overwrite

Allow overwriting out_file if it is already backed by H5Array analysis data. Ignored (always allowed) when out_file is not given

Default:

False

Arguments

DATASET_FILE

Required argument

Simulation dataset HDF5 file

compute_model_prob

Compute methylation probabilities via a calibrated log-odds model.

Usage

catella compute_model_prob [OPTIONS] SOURCE_FILE

Options

--prob-name <prob_name>

Key for storing methylation probabilities

Default:

'meth_prob'

--pi0 <pi0>

Prior probability a site is methylated

Default:

0.5

--eta <eta>

Log-odds correction for correlated sites. A number applies to every channel; a JSON object pins only the named channels, e.g. ‘{“M6A”: 0.9, “HCG”: 0.7}’. Omit to auto-estimate every channel (default).

--eta-max-lag <eta_max_lag>

Max lag (bp) for eta auto-estimation

Default:

10

--store-rho, --no-store-rho

Store the lag-k autocorrelation rho(k) used in eta estimation

Default:

False

--nu <nu>

Pseudo-count shrinkage strength

Default:

10.0

--rho-leak <rho_leak>

Leak fraction toward accessible-state rate

Default:

0.1

--min-gap <min_gap>

Min accessible/protected rate gap to be informative

Default:

0.05

--lnuc <lnuc>

Nucleosome footprint / window size (bp)

Default:

147

--n-min <n_min>

Min context-eligible sites per window (no-controls fit)

Default:

10

--max-iters <max_iters>

Max EM iterations (no-controls fit)

Default:

200

--init-prot <init_prot>

Initial protected-state rate (no-controls fit)

Default:

0.05

--init-acc <init_acc>

Initial accessible-state rate (no-controls fit)

Default:

0.95

--tol <tol>

EM log-likelihood convergence tolerance

Default:

1e-08

--fill-edge <fill_edge>

Probability for the unfilled trailing edge

Default:

nan

--norm-by-strand, --no-norm-by-strand

Normalize by strand

Default:

False

--batch-size <batch_size>

Molecules processed per batch

Default:

20000

--mask-name <mask_name>

Key of a prior filter_dropout mask to apply

--out-file <out_file>

Output file (default: overwrite source_file)

--overwrite, --no-overwrite

Allow overwriting out_file if it is already backed by H5Array analysis data. Ignored (always allowed) when out_file is not given

Default:

False

Arguments

SOURCE_FILE

Required argument

Experiment HDF5 file

downsample

Downsample an analysis array and store the result under a new key.

Usage

catella downsample [OPTIONS] SOURCE_FILE CHROM KEY MAX_ROWS

Options

--kind <kind>

Required Whether source_file holds a MethPrintExperiment or a SimDataset

Options:

experiment | dataset

--how <how>

mean, sum, min, max, or stride

Default:

'mean'

--batch-size <batch_size>

Rows read per streamed chunk

Default:

20000

--out-key <out_key>

Key to store the result (default: ‘<key>_downsampled’)

--out-file <out_file>

Output file (default: overwrite source_file)

--overwrite, --no-overwrite

Allow overwriting out_file if it is already backed by H5Array analysis data. Ignored (always allowed) when out_file is not given

Default:

False

Arguments

SOURCE_FILE

Required argument

Experiment or dataset HDF5 file

CHROM

Required argument

Chromosome name

KEY

Required argument

Analysis key to downsample

MAX_ROWS

Required argument

Target number of rows

Subset of chromosomes to load

False

--ignore-strand, --no-ignore-strand

Ignore recorded strand for mtase context filtering

Default:

False

ModKit column indices

--max-nmol <max_nmol>

Max molecules per chromosome

--seed <seed>

Seed for molecule sampling

--tmp-dir <tmp_dir>

Scratch directory

Rows read per streamed chunk

Default:

1000000

--max-cached-chroms <max_cached_chroms>

Max chromosomes’ raw data kept in memory

Default:

1

--nworker <nworker>

Threads for parallel file reading

Default:

1

Required argument

Chromosome sizes file

Required argument

Path to save results
